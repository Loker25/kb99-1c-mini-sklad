# Мини-Склад

Учебный проект на платформе **1С:Предприятие 8.3**, разработанный в рамках обучения от компании КБ99. Проект предназначен для изучения базовых объектов конфигурации, складского учёта, регистров, отчётов, печатных форм и работы с Git.

## Назначение проекта

«Мини-Склад» - учебная конфигурация для оформления поступления и реализации товаров, учёта остатков по складам, хранения цен и получения отчётных данных.

## Состав конфигурации

### Справочники

- **Товары** - хранение сведений о товарах.
- **Контрагенты** - хранение сведений о поставщиках и покупателях.
- **Склады** - хранение информации о складах.

### Документы

- **ПоступлениеТоваров** - оформление поступления товаров и формирование приходных движений по регистру остатков.
- **РеализацияТоваров** - оформление продажи товаров и формирование расходных движений по регистру остатков.

В документах предусмотрена табличная часть `Товары` с реквизитами `Товар`, `Количество`, `Цена` и `Сумма`. Сумма строки рассчитывается автоматически при изменении количества или цены.

### Регистры

- **Регистр накопления `ОстаткиТоваров`** - учёт количества товаров на складах, приходов, расходов и остатков.
- **Регистр сведений `Цены`** - хранение цен товаров с учётом даты их действия.

При выборе товара в документе реализации цена подставляется автоматически по данным регистра на дату документа. Если актуальная цена не найдена, пользователь получает предупреждение.

### Общие модули

- **`РаботаСДокументами`** - общая логика пересчёта суммы строки табличной части.
- **`РаботаСоСправочниками`** - получение актуальной цены товара из регистра сведений.

### Отчёт

- **`ОборотыПоТоварам`** - отчёт на основе системы компоновки данных (СКД). Используется виртуальная таблица `ОстаткиТоваров.ОстаткиИОбороты`. Отчёт показывает склад, товар, начальный остаток, приход, расход и конечный остаток за выбранный период.

### Печатная форма

- Для документа **`РеализацияТоваров`** создана команда `Печать` и макет печатной формы.
- Печатная форма содержит реквизиты документа, строки с товарами, количеством, ценой и суммой, а также общую сумму документа.

## Структура репозитория

- `Неделя1/` - выгрузка конфигурации, созданная в рамках первой недели практики.
- `Неделя 2/` - версия конфигурации с доработками второй недели: регистр цен, автоматическая подстановка цены, отчёт СКД и печатная форма реализации.
- `README.md` - описание проекта и инструкция по загрузке конфигурации.
- `.gitignore` - правила исключения файлов, которые не следует добавлять в Git.

## Загрузка конфигурации

1. Склонировать репозиторий или скачать архив с GitHub.
2. Создать новую пустую информационную базу 1С без конфигурации.
3. Открыть базу в режиме «Конфигуратор».
4. Выбрать **Конфигурация → Загрузить конфигурацию из файлов**.
5. Указать каталог нужной версии: `Неделя1/` или `Неделя 2/`.
6. Дождаться загрузки, сохранить конфигурацию и выполнить обновление конфигурации базы данных.
7. Запустить приложение в режиме «1С:Предприятие».

Для проверки работы рекомендуется создать и провести документы поступления и реализации, заполнить регистр `Цены` тестовыми данными, сформировать отчёт за выбранный период и проверить печатную форму документа реализации.
