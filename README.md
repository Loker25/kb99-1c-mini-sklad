# Мини-Склад

Учебный проект на платформе **1С:Предприятие 8.3**, созданный в рамках практики по изучению базовых объектов конфигурации и работы с Git.

## Назначение проекта

«Мини-Склад» предназначен для изучения основ складского учёта: хранения сведений о товарах и контрагентах, оформления поступлений и реализаций товаров.

## Состав конфигурации

- **Подсистема «Мини-Склад»** – основной раздел пользовательского интерфейса.
- **Справочник «Товары»** – хранение сведений о товарах.
- **Справочник «Контрагенты»** – хранение сведений о поставщиках и покупателях.
- **Справочник «Склады»** – хранение сведений о складах.
- **Документ «ПоступлениеТоваров»** – оформление поступления товаров.
- **Документ «РеализацияТоваров»** – оформление реализации товаров.
- **Общие модули** – размещение общей программной логики.
- **Регистр накопления** – учёт движений и остатков товаров.

В документах предусмотрены товарные позиции с количеством, ценой и суммой. Сумма строки рассчитывается автоматически при изменении количества или цены.

## Структура репозитория

- `Неделя1/` – выгрузка конфигурации 1С в файлы.
- `README.md` – описание проекта и инструкция по его загрузке.
- `.gitignore` – правила исключения временных и служебных файлов.

## Загрузка конфигурации

1. Склонировать репозиторий или скачать его архив с GitHub.
2. Создать новую пустую информационную базу 1С без конфигурации.
3. Открыть базу в режиме «Конфигуратор».
4. Выбрать команду «Конфигурация → Загрузить конфигурацию из файлов».
5. Указать каталог `Неделя1/`, содержащий выгруженные файлы конфигурации.
6. Сохранить конфигурацию и обновить конфигурацию базы данных.
7. Запустить приложение в режиме «1С:Предприятие» и проверить доступность объектов.
